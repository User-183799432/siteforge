# SiteForge V2

A local-first visual website builder designed for editable AI-generated website projects.

## V2 upgrades
- Nested sections, containers, grids, and cards
- Editable headings, text, buttons, images, spacers, dividers
- Common layout and typography sliders
- Exact CSS per element
- Tablet and mobile CSS overrides
- Pixel-match reference image overlay with opacity control
- Undo / redo
- Autosave in the browser
- Save/open `.siteforge.json` project files
- Preview and standalone HTML export
- No account, analytics, ads, or external JavaScript libraries

## Run
Open `index.html` in a modern browser or publish these files with GitHub Pages.
