# SiteForge V1

SiteForge is a local-first visual website builder: add blocks to a canvas, select them, then adjust size, spacing, typography, alignment, color, and layout with visual controls.

## V1 features

- Add Section, Heading, Text, Button, Image, Spacer, Divider, and Columns blocks
- Drag new blocks onto the page or click to add them
- Drag existing blocks to reorder them
- Double-click headings, text, and buttons for direct editing
- Inspector controls for width, height, font size, font weight, alignment, margins, padding, colors, and corner radius
- Desktop, tablet, and mobile canvas widths
- Automatic local browser saving
- Save/open portable `.siteforge.json` project files
- Full-page preview
- Export the current design as a standalone HTML website
- Undo/redo for structural edits
- No accounts, ads, analytics, or external JavaScript libraries

## Run

Open `index.html`, or visit the GitHub Pages deployment once Pages is enabled.

## Roadmap

V2 will focus on true nested sections and columns, local image uploads, stronger undo/redo, multi-page sites, reusable templates, and better responsive controls. AI-assisted initial designs come after the manual editor is solid.

## Privacy

Editing happens in the browser. V1 stores its autosave in browser local storage and does not send project content to a SiteForge server.
